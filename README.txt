SCSVMV COLLEGE ENQUIRY CHATBOT - UPDATED PROJECT

Run in VS Code on Windows:
1. Extract this ZIP file.
2. Open the extracted CollegeEnquiryChatbot folder in VS Code.
3. Choose Terminal > New Terminal.
4. Run: python -m pip install flask
5. Run: python app.py
6. Open http://127.0.0.1:5000/ in your browser.

Files:
- app.py: Flask website server and chatbot API
- chatbot.py: college enquiry answers and topic matching
- templates/index.html: website and chat interface
- college details.txt: college information notes
- requirements.txt: dependencies

Topics include college contacts, courses/departments, fees, admissions, scholarships, placements, faculty, timetable, CSE course structure, examinations, attendance, hostel/rooms/food, transport routes and fees, library, Wi-Fi, laboratories, medical support, teaching, accreditation, sports, campus facilities, cultural festivals, classical music and yoga.

Important: Some figures and operational details are indicative or unverified. Confirm current fees, faculty, routes, timetables, attendance rules, accreditation and placement statistics with the university before relying on them. This runs locally on your computer; it is not a public website.
